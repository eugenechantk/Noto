### 2026-06-07 — Design-asset download via preview-token fetch was a rabbit hole

**What happened:** To ground-truth the AI Chat design for implementation, I tried to pull the
current `Noto AI Chat.html` + `noto-ai-chat.jsx` from the claude.ai/design preview origin
(`<id>.claudeusercontent.com`) via `fetch` with the MintPreviewToken token. GetProject returns the
project (files embedded in chat history, not as plain files); preview-origin `fetch` 404'd whether
the token was a query param or omitted, cross-origin fetch from the design tab hit CORS, and direct
navigation to the `.jsx` with token also 404'd. Spent ~6 tool calls before stopping.
**Why this was inefficient:** The skill's own guidance is the UI right-click → Download flow (with
`collect_assets.py`) until the API path is *validated*; I jumped to the unvalidated headless API. And
I already had a complete spec to implement from (concept doc + first-hand inspection of all 13
artboards + local `Design/v2` shared tokens + the package handoff), so the download wasn't blocking.
**What better looks like:** For claude.ai/design assets, use the documented UI download flow, or just
proceed from the design knowledge already in hand and pull files only when the verifier needs a local
render. Honor the browser "stop after 2–3 failed attempts" rule sooner.

### 2026-06-07 — Swift Testing parallelism raced on shared static mock state

**What happened:** Two `OpenRouterClientTests` failed on first run — a JSON decode error reading
`"data:"` (another test's SSE body) and an expected-error that wasn't thrown. Root cause: Swift
Testing runs tests in parallel by default, and the tests shared `MockURLProtocol`'s static
`responseData`/`statusCode`, so they clobbered each other.
**Why it matters:** Easy to misread as a real bug in the client. The code was correct.
**What better looks like:** Any test suite that mutates shared static state (URLProtocol mocks,
global config) must be `@Suite(.serialized)`, or carry per-request state instead of statics. Reach
for `.serialized` the moment a mock holds `static var`.
